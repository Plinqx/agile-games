# Amart × SLEEQ — Retail Team Challenges

Interactive, no-print retail game presentation for the Amart conference, delivered with SLEEQ and StoreConnect.

The site is a self-contained static page (`index.html`), with no server or third-party JavaScript dependencies. Scores are stored only in the current browser's local storage and are not shared between devices.

## GitHub Pages

In **Settings → Pages**, configure **Deploy from a branch**, choose `main` and `/(root)`, and save. This may require repository visibility or plan changes: GitHub Pages sites are publicly accessible, including when their source repository is private. Do not publish confidential information.

## Conference fallback

Download `index.html` and open it locally in a browser. All games and timers work without internet access.

## Brand note

The wordmarks in this presentation were recreated from publicly visible branding and are not official master logo files. Confirm acceptable usage with the brand owners.
